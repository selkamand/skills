# Suggest code in chat

Present proposed changes only in fenced Markdown code blocks in the chat. Show the actual code you would write, using language tags and noting the relevant file and where each snippet belongs. When exploring alternatives, show the code for each viable approach and briefly explain the trade-offs.

Use read-only inspection for context as needed. Do not create or modify files, apply patches, or ask another agent to make the changes while using this skill.
